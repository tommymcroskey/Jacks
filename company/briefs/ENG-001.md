# ENG-001: smallest useful portfolio ledger

Status: proposal awaiting cross-review. Author: Senior Engineer agent. Project: P001.

## Purpose and boundary

Explain changes in portfolio value using a small deterministic ledger: a record of cash, asset units, and the events that change them. Equity means cash plus the position's value at the latest observed price. Deposits increase equity without being trading profit.

Propose a C++17 core with one state transition function and one valuation function. Input is a starting state and an ordered sequence of typed events; output is either the resulting state and accounting summary or a specific validation error. Keep file parsing, price downloads, trading signals, order execution simulation, and persistence outside this component. A test executable can supply tiny examples directly.

Use one currency, one asset, whole nonnegative asset units, and signed 64-bit integer minor currency units for money and per-unit prices. This deliberately limits the first examples so fractional-unit rounding is unnecessary. Check arithmetic overflow before mutation. Risk and research must review this restriction before implementation. Defer dividends and splits to a follow-up.

## Contract to agree before implementation

- Events: deposit, withdrawal, executed buy, executed sell, and valuation price update. Trades carry their own execution price and nonnegative fee; a valuation update supplies the observed price used to value holdings. A trade does not silently replace that valuation price.
- Order: consume explicit sequence numbers, reject duplicate or decreasing sequence numbers, and value only after the current event. Equal timestamps require sequence ordering. No calculation can consult later events or prices.
- State: cash, held units, optional latest valuation price, cumulative signed external flows, and cumulative fees. Reject unaffordable buys/withdrawals, overselling, nonpositive trade quantities/prices, negative fees, and invalid price updates. Invalid events leave the prior state unchanged. A positive holding without an observed valuation price has unavailable equity, never an invented zero valuation.
- Reconcile every accepted event: cash and holdings must match their starting balances plus event movements. For a period without missing valuations, profit equals ending equity minus starting equity minus net external deposits. Fees already reduce cash; do not subtract them twice.
- Record units, initial state, event order, error behavior, overflow policy, and treatment of missing prices in one short agreed contract. Tests must distinguish execution price from valuation price.

These are suggested rules, not accepted economic conventions or implemented behavior.
